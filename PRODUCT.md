# Ludo Super League

A public penalty leaderboard for a group of friends in Évry, with a private scorekeeper. Higher totals indicate more penalties, not more wins. Ties use player creation order. Active players and limited score history are public; score reasons and signed receipts are private unless a scorekeeper explicitly approves selected reasons for publication on a certificate. Admins add, edit, archive, award, and correct scores through existing Supabase RPCs.

The public history contains player IDs, signed point changes, timestamps and event numbers. It does not contain match IDs, match results, opponents, attendance, or wins. Never infer win rates, games played, head-to-head results, or streaks from these events.

The user rejected a spacious landing-page layout. The requested surface is a dense, useful league dashboard with black/green styling, a small pink accent, Grafana-like labelled charts, detailed player workspaces, responsive layouts and production verification. Existing authorization includes merging tested improvements to main and deploying GitHub Pages.

Certificates are centered charcoal/green/pink recognitions with a special gold crown edition for #1. Every player has an unissued preview; authenticated scorekeepers can explicitly approve and publish selected original scoring comments and an optional personal message. Issuance creates a permanent server-side snapshot, independent of future standings, with QR, clickable PDF verification links and public verification/revocation states. PDF and 3500 × 2475 PNG pages share the renderer; long messages and comment collections use attachment pages, with PNGs bundled in ZIP. Demo records are browser-local and never described as public verification. These are penalty recognitions, not match-win awards or digitally signed credentials. Archived player preview links never silently select another recipient; existing issued records remain accessible.
