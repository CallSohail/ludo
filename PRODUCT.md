# Ludo Super League

A public penalty leaderboard for a group of friends in Évry, with a private scorekeeper. Higher totals indicate more penalties, not more wins. Ties use player creation order. Active players and limited score history are public; score reasons and signed receipts are private. Admins add, edit, archive, award, and correct scores through existing Supabase RPCs.

The public history contains player IDs, signed point changes, timestamps and event numbers. It does not contain match IDs, match results, opponents, attendance, or wins. Never infer win rates, games played, head-to-head results, or streaks from these events.

The user rejected a spacious landing-page layout. The requested surface is a dense, useful league dashboard with black/green styling, a small pink accent, Grafana-like labelled charts, detailed player workspaces, responsive layouts and production verification. Existing authorization includes merging tested improvements to main and deploying GitHub Pages.

Certificates are personal, dated recognitions derived from the current penalty table. Automatic commendations and an optional device-local message appear in both high-resolution PNG and A4 landscape PDF downloads. The #1 gets a crown edition and persistent site spotlight. These are not match-win awards or digitally signed credentials; private scorekeeper reasons are excluded. Old or archived player links must not silently issue another player's certificate.
